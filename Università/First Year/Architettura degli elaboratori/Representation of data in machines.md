# Bits, Nibbles e bytes
___
- Un <font style="color:Indianred">Bit</font> è un elemento che può essere 0 o 1.

- Un <font style="color:Indianred">Nibble</font> è una sequenza di <font style="color:Indianred">4</font> bit.

- Un <font style="color:Indianred">Byte</font> è una sequenza di <font style="color:Indianred">8</font> bit.
