#java #primitives #types 
___
In Java i tipi principali built-in sono:
- double (8 byte)
- long (8 byte)
- int (4 byte)
- float (4 byte)
- short (2 byte)
- byte (1 byte)
- Boolean
	Logic
		And = &&
		Or = ||
		Not = !
		Xor = ^
- char (Unicode)
	delimitato da ' '
- String (non realmente primitivo)
	delimitato da " "
