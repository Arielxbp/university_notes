- I tipi di dati di base sono built-in, cioè sono predefiniti nel linguaggio Java.

L'elenco dei tipi di dati di base sono:

- double (numeri)
- long (numeri)
- int (numeri)
- float (numeri)
- short (numeri)
- byte (numeri)
- boolean (true, false)
- char (caratteri)
