Esistono $4$ [[Keywords|keyword]] riguardanti la <font style="color:springgreen">visibilità</font>:

- <font style="color:salmon">Default</font>

- <font style="color:salmon">public</font>

- <font style="color:salmon">protected</font>

- <font style="color:salmon">private</font>

# Default

- Visibile all'interno di tutte le classi del package.

# Public

- visibile a tutti (all'interno di un modulo, [[Later Introduced things|per Java 9 in poi]]).

# Protected

- visibile all'interno di tutte le classi del package e delle sottoclassi, <font style="color:salmon">indipendentemente dal package</font> (riferito alle sottoclassi).

- qualcosa definito <font style="color:springgreen">protected</font> avrà visibilità protetta, cioè visibile a tutte le [[Inheritance|sottoclassi]] ma anche a tutte le [[Classes|classi]] presenti <font style="color:salmon">all'interno del package</font>.

# Private

- visibile solo all'interno della classe.
